# Documentation scope

`product/`는 2026-09-10 foundation 요청에서 확정한 frozen authority다. `context/`의 오래된 제안을 현재 규칙으로 가져오지 않는다. Gap은 `architecture/open-questions.md`와 proposed ADR에 기록한다. Engineering decision과 product fact를 구분하고, 기존 ADR history를 숨기기 위해 다시 쓰지 않는다. 상대 link와 code/config reference는 `scripts/check_repository.py`로 검증한다.
